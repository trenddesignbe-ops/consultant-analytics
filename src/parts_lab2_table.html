Classement

Le plus facile pour moi : CSS pur, GSAP, effets Codrops, WAAPI, Rough.js, SplitType, Flip. Le plus beau rendu obtenu : modèle glTF en verre, Rough.js, Spline, Flip, cartes Codrops, vidéo WebM. Le plus convaincant pour le persona : Rough.js (avant / après), Flip (chiffres qui se rangent), cartes Codrops (12 contre 10), SplitType (phrase qui se corrige), Matter.js (pièces dans le bocal).

Ma recommandation : CSS + GSAP + Lenis comme socle, Rough.js et Flip pour les démonstrations, un seul objet 3D (glTF depuis Spline ou Blender) ou une vidéo WebM dans le hero, Rive plus tard pour les pictogrammes si tu apprends l'éditeur. Rien d'autre.
